# Davidson Well Drilling, Inc. — Multi-Page Website Redesign

Complete 6-route React + Vite + Tailwind CSS v4 + GSAP + React Router application for Davidson Well Drilling, Inc. (Est. 1973), serving Northeast Georgia and Upstate South Carolina.

## Routes
- `/` — Homepage (Hero, Introduction, Our Expertise Showcase, How We Work, Why Davidson Standards, Technical Service Badges, Our Work Preview, Testimonials, Final CTA, Footer)
- `/services` — Services (Dedicated alternating compositions for Water Well Drilling, Hydrofracturing, Geothermal Ground Loop System, Vertical Ground Loop Drilling, and Downhole Installation & Pump Service)
- `/about-us` — About Us (Company Story, Heritage Timeline, Northeast Georgia & Upstate South Carolina Service Area, Values)
- `/our-work` — Our Work (Category-filtered asymmetrical field gallery with click-to-expand lightbox)
- `/faqs` — FAQs (Sticky category navigation + accessible expandable accordions)
- `/request-estimate` — Request an Estimate (Validated multi-field project inquiry form + direct contact details)

## Local Setup
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
